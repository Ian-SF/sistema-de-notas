# sistema-de-notas

Projeto desenvolvido em Python para praticar conceitos fundamentais de programação.

O programa recebe as notas dos alunos, calcula as médias e apresenta informações sobre o desempenho da turma.

📚 Conceitos praticados
Variáveis
Listas
Estruturas condicionais (if / else)
Estruturas de repetição
Cálculo de médias
Entrada e saída de dados

Python
